# Clearpath jackal Description
This is an autogenerated package for the clearpath jackel robot used for this project. This includes the urdf, srdf, ros2 control, and sensor parameter files. 

## Installation

## Dependencies
- ROS2 Jazzy +


## Usage
Clearpath offers desktop and simulator packages that use the robot description package. These packages can be found in the tutorials.
